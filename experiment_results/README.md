# Experiment results

Nixround contains the final results, with both the hsort and long runs.

"ryddet" and "short" contain the long and short runs from the iteration prior to the final results.

"scaling_freq_results" contains results for the scaling_freq tool.

Note that for "ryddet" there is a fifth Linux configuration, optimized_linux_wo_iso_eist_c-state_on, which is not included in the final results.
