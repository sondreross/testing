## Data analysis

This is the data analysis area of the repository. Most notebooks are not the final results.

[frequency_energy_analysis.ipynb](./frequency_energy_analysis.ipynb) is the notebook used for energy data analysis with the scaling_freq tool (see [freq_scaling_tool](https://github.com/sondreross/freq-scaling-tool/tree/main)).

[ryddet_plots.ipynb](./ryddet_plots.ipynb) and [short_plots.ipynb](./short_plots.ipynb) are from the previous iteration of the experiment, for long and short plots. These were created before discovering issues with dynamic and static linking (see thesis).

The final data analysis is in [nixround_short_plots.ipynb](./nixround_short_plots.ipynb) and [nixround_long_plots.ipynb](./nixround_long_plots.ipynb).
