## Data analysis

This is the data analysis corner of this repo. Most of these are not the final results.

[frequency_energy_analysis.ipynb](./frequency_energy_analysis.ipynb) is the file used for energy data analysis for the scaling_freq tool is placed (see [freq_scaling_tool](https://github.com/sondreross/freq-scaling-tool/tree/main)).

[ryddet_plots.ipynb](./ryddet_plots.ipynb) and [short_plots.ipynb](./short_plots.ipynb) are both the previos iteration of the experiment, for long and short plots. Before finding out the issues with dynamic and static linking (see thesis). 

The final data analysis, is in the [nixround_short_plots.ipynb](./nixround_short_plots.ipynb) and [nixround_long_plots.ipynb](./nixround_long_plots.ipynb).
