# Testing
This repository contains experiment code, results, and data analysis. The actual results from this thesis are in [./experiment_results/nixround/](./experiment_results/nixround/).

## Overview
The benchmarks are in [./benchmarks/](./benchmarks/).

In [data_analysis](./data_analysis/), the notebooks used for data analysis are placed.

In [experiment_results](./experiment_results/), the actual results for the different experiments are placed.

[power_monitor.cpp](./power_monitor.cpp) is the program run on the external machine that communicates with the power monitor and DUT.

[setup_isolation.sh](./setup_isolation.sh) is the script mentioned in the thesis, used for part of the Linux ISO configuration.
