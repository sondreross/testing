# IncludeOS setup

To run this you have to be on the correct version of [IncludeOS](https://github.com/sondreross/IncludeOS/tree/bench_func), and use the devolp.nix, and compile the CMakeLists.txt from that nix-shell enviorment. This is described in the thesis. After compiling, make_grub_iso.sh can be run to make a bootable .iso image from the IncludeOS binary.

This IncludeOS version is also needed as we have implemented the actuall measurments there.
